# The Edge of Obsidian

A work-in-progress, text-based narrative RPG developed in Python.

## About the Project

The Edge of Obsidian is an interactive mystery RPG in which players make decisions, investigate clues, and experience branching dialogue.

The story follows Miles Carter as he begins investigating the mysterious circumstances surrounding his best friend's death.

## Current Features

- Three playable character classes with different attributes
- D20-based ability checks
- Three optional rerolls per playthrough
- Inventory and clue tracking
- Branching dialogue based on player choices
- Multiple interconnected scenes

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run `python main.py` in your terminal.
